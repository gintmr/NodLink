# NodLink 调试台

Mac 端的中继服务和调试网页，用来调试校准、滤波和精度测试算法，也是日常使用头控的控制台。

```bash
cd web
npm install
npm start          # 打开 http://localhost:8787
npm test           # 用模拟头部检验核心算法
npm run fake-source  # 假的 iOS 数据源，用来测试“实时”通路
```

## 界面

没有首页和面板，整个窗口是一个 3D 书桌场景：小机器人戴着 AirPods 站在桌上，面前是按真实排列摆放的显示器。

- **点部件看数据**：耳机（数据源、采样率、姿态）、机器人（正前方、中心校准、轴方向）、紫色视线（多屏定点、路径校准）、屏幕上的光标（模式、灵敏度、接管系统鼠标）、每块显示器（精度测试）。卡片在部件旁边展开。
- **暗驾驶舱**：正常时不显示数字；出问题的部件亮琥珀色或红色，旁边浮出短标签，点标签直接展开。
- **探针**：在卡片里点“钉住”，读数或波形就留在部件旁边，跟着走（属于调试镜头）。
- **时间轴**：底部唯一常驻的界面，画着头部活动和事件；拖动回看过去，双击或点“实时”回到现在。
- **镜头**：演示（彩色）和调试（变灰，显示坐标轴、九宫格、误差线、探针）。
- **更多**：角色、屏幕距离、模拟参数、导出、快捷键。

校准和测试时，红点由耳机桥画在真实显示器上；没有耳机桥时用浏览器全屏，再不行就铺满页面。

## 试一试

顶栏“试一试”进入（`public/ui/challenge.js`，样式在 `public/challenge.css`）。四个小场景，每个几步就做完，做错只提示、不罚分。点首页的卡片可以单独做某一个场景。

和游戏厅不同，这里**不交还系统鼠标**：头控、语音指令、歪头按键都走真实的系统光标和键盘事件。没接管鼠标时用普通鼠标也能走一遍。

| 场景 | 步骤 | 歪头场景 |
|---|---|---|
| 关掉弹窗 | 5 个不同的窗口依次出现，分别点「稍后」「仅必要」「不允许」「保存」和广告的 × | 沿用设置 |
| 刷短视频 | 下一条 → 双击画面点赞 → 单击暂停 → 打开评论 → 关掉评论 | 抖音 |
| 回消息 | 点输入框，左歪说一句话，回正，右歪发送；再点笑脸发 👍 | 语音输入 |
| 点外卖 | 选牛肉面 → 选 12:30 → 说出备注“放门口” → 提交 | 语音输入 |

每个场景会临时切到对应的歪头场景，退出后恢复设置里选的。每次的用时、步数、点错次数存在浏览器本地（`nodlink.tryit.runs`），总结页“导出记录”可以下载（JSON）。短视频是画布实时画的抽象画面，不用任何平台的素材和商标。

## 体感游戏

顶栏“游戏”进入游戏厅（`public/ui/arcade.js`），游戏都在 `public/ui/games/`，公共的头部输入、手势、音效和空间音频在 `kit.js`。全程可以只用头：转头选游戏、点头开始，结算时点头再来一局、摇头回大厅。没戴耳机时，在“更多”里切到模拟数据，用鼠标代替头，`[` `]` 代替歪头。

| 游戏 | 怎么玩 |
|---|---|
| 声纳猎手 `sonar.js` | 空间里看不见的目标在“嘀”，声音用 HRTF 钉在空间里；跟着声音转头，对准后点头锁定。闭着眼也能玩 |
| 穿墙光缝 `slot.js` | 墙飞过来，转头对准缝的位置、歪头对准缝的角度，穿过去 |
| 点头节拍 `beat.js` | 合成音乐里跟着拍子点头、抬头、左右歪头、摇头；判定会自动补偿手势识别的延迟 |
| 光刃 `blade.js` | 快速甩头挥出光刃，切开抛起来的发光晶体，躲开虚空核 |
| 疾行 `runner.js` | 三车道霓虹跑酷：转头换道、抬头跳、低头滑 |

进游戏厅时会全屏，并且先交还系统鼠标（头只在游戏里用，不会把真光标甩到别的屏幕），退出后自动接回。手势在动作最高点就判定，不用等头回正；认出来的手势会在画面底部亮一下。

每局的最好成绩存在浏览器本地（`nodlink.arcade.best`）。新加游戏：照 `sonar.js` 的结构写一个模块，在 `games/index.js` 里登记。

## 公开体验版

`npm run build:public` 把同一份 `public/` 构建成纯静态网页（`dist/`），推到 `main` 后由 `.github/workflows/pages.yml` 自动发布到 GitHub Pages。页面带 `data-edition="public"` 时只用模拟数据，`class="live-only"` 的界面（数据源切换、接管鼠标、语音指令、耳机连接）都藏起来；`class="public-only"` 的只在体验版出现。`npm run preview:public` 在 http://localhost:8790 预览。

资源路径都写成相对路径（`sprites/…`、`vendor/…`），因为体验版挂在 `https://gintmr.github.io/NodLink/` 这样的子路径下。

## 代码结构

| 文件 | 内容 |
|---|---|
| `server.js` | 静态文件服务和 WebSocket 中继 |
| `public/core/` | 与界面无关的算法：角度、校准、滤波、光标、精度测试、模拟头部 |
| `public/app.js` | 网页逻辑：数据源、校准和测试流程、状态 |
| `public/ui/scene3d.js` | 3D 视口（three.js，由本地服务从 node_modules 提供，离线可用） |
| `public/models/` | 3D 模型。内置机器人和书桌摆件（均为 CC0），其他本地模型不提交 |
| `public/ui/timeline.js` | 时间轴 |
| `test/` | 核心算法测试 |
| `tools/fake-source.js` | 假数据源 |
